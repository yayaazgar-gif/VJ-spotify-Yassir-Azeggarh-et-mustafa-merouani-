# Spotify Clone – Vue 3

Clone de Spotify fait avec Vue 3 (sans installation, sans npm).

## Fichiers
- `index.html` : la page principale (à ouvrir)
- `style.css` : le design
- `player.js` : les titres, les playlists et le lecteur audio
- `app.js` : l'application Vue (menus, pages, boutons)

## Utilisation
Télécharge les 4 fichiers dans le même dossier puis ouvre `index.html` dans ton navigateur.
Une connexion internet est nécessaire (chargement de Vue et de la musique).
